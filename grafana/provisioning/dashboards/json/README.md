# Dashboard JSON Files Directory

Place your exported Grafana dashboard JSON files here.

They will be automatically imported on Grafana startup.

## Recommended Dashboards

Instead of placing files here, you can import dashboards directly in Grafana UI:

1. Go to **Dashboards** → **Import**
2. Enter Dashboard ID:
   - **1860** - Node Exporter Full
   - **179** - Docker Container & Host Metrics
   - **14282** - cAdvisor Exporter
   - **2** - Prometheus Stats

These will be imported from grafana.com automatically.
